# Goldstein reading map

Task 0 of Module 01. Built from the table of contents of Goldstein, Poole and Safko, *Classical Mechanics*, 3rd edition.

**How to read the page ranges.** A range runs from the first page of the section to the page before the next section starts. Sections can share a page, so the last page may be partial.

**Columns left for you.** "Worked examples?" cannot be read from a table of contents. Fill it in as you open each section.

## 2. Corrections to the guide

The module files cite section numbers that are off by one from 9.3 onward in Chapter 9. The corrections:

| Where in the guide | Says | Should say |
| --- | --- | --- |
| README table and Module 08 | 9.1 to 9.2 | 9.1 to 9.3 |
| README table and Module 09 (header, sessions A1 and A2) | 9.3 to 9.4: A1 "9.3, symplectic condition", A2 "9.4, Jacobi identity" | 9.4 to 9.5: A1 "9.4, symplectic approach", A2 "9.5, Poisson brackets and canonical invariants (Jacobi identity)" |
| README table and Module 10 (header, sessions A1 to A3) | 9.5 to 9.8 | 9.6 to 9.9: A1 "9.6 (first half)", A2 "9.6 (conservation) and 9.7 (angular momentum brackets)", A3 "9.8 (symmetry groups) and 9.9 (Liouville)" |

| README table and Module 16 | 10.8 or 10.9 | none in this edition; use Dirac (1933), Feynman and Hibbs, and the WKB sections already listed |
| README table and Module 19 | 13.7 and 13.8 | 13.7 only |
